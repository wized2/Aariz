Native Android AI chat by Project Endroid.

**Install:** download the `Aariz-v*.apk` below and open it. Verify it with `SHA256SUMS.txt` (`sha256sum -c SHA256SUMS.txt`).

- Chat, web search and image modes
- Full Markdown (tables, italic, links, lists, quotes), selectable text
- Run code: JavaScript on the device, many more languages online, HTML/SVG preview
- Edit your messages, download generated images
- Material 3 interface with light and dark themes
- Minified and shrunk release build
