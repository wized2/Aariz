# Aariz

**Aariz** is a mobile AI chat app by **Project Endroid** (Mudasir Wazir) — native Android companion to the [web app](https://wized2.github.io/Ai/).

## Features

- Chat with the Aariz worker (`ai.endroid.workers.dev`)
- Local chat history (DataStore)
- Light / dark / system theme
- Web search and image modes
- Material 3 + **Lucide** icons
- Fern-style CI (debug + release; optional Play signing secrets)

## Stack

- Kotlin · Jetpack Compose · Material 3
- OkHttp · DataStore · Lucide (compose-icons)

## Build

```bash
./gradlew assembleDebug
```
